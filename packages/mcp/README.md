# @spear-secure/mcp

MCP (Model Context Protocol) server that exposes Spear security gates to any MCP-compatible client — Claude Desktop, Cursor, Windsurf, and others.

**Status: Planned**

Planned functionality:
- Expose `pre()` and `post()` as MCP tools
- Session-scoped security context across tool calls
- Policy management via MCP resources
- Works with any MCP-compatible LLM client
